# Hemashree Samant — Portfolio

A responsive personal portfolio for marketing, SEO, content and growth strategy.

## GitHub Pages

In this repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/ (root)**, then **Save**.

The site will be hosted at `https://hemusamant222-droid.github.io/HemashreeSamant/` after GitHub completes deployment.

## Editing

- `index.html`: content and page structure
- `style.css`: visual design and responsive CSS illustration
- `script.js`: accessible reveal animations
- `assets/Hemashree-Samant-Resume.pdf`: downloadable résumé

No build step or paid domain is required.
